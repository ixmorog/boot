Arch workstation boot

Boot the official x86_64 Arch ISO in UEFI mode, connect to the internet and run as root:

curl -fsSLo /run/boot https://ixmorog.github.io/boot/run && bash /run/boot

Enter the displayed code at github.com/login/device using your phone or another computer. The installer wizard starts after you sign in.

This public launcher contains no workstation settings or secrets. It downloads the installer from a private repository. You choose the disk and confirm in the wizard.
